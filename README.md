# SkyFitnessPro

Дипломный проект. Сайт с фитнес-курсами на React и TypeScript.

Список курсов грузится с бэка. Можно залогиниться, добавить курс в профиль, открыть урок с видео и упражнениями. По каждому упражнению пишешь, сколько раз сделал, прогресс сохраняется.

## Что сделано

- Главная: карточки курсов, кнопка добавить в профиль (если не залогинен - открывается окно входа).
- Страница курса: описание, блок "подойдет для вас", направления, кнопка добавить курс.
- Вход и регистрация: модальное окно по кнопке "Войти", после входа редирект в профиль.
- Профиль: аватарка, имя, кнопка выйти. Список моих курсов с прогрессом в процентах. Можно удалить курс или нажать "начать/продолжить" и выбрать урок.
- Урок: видео (ютуб), список упражнений с прогресс-барами. Кнопка "обновить прогресс" открывает форму, вводишь кол-во повторений, сохраняется на бэк.
- Адаптив: верстка под мобильные и десктоп.

## Стек

React 18, TypeScript, Vite, Tailwind CSS. Запросы к API через axios. Роутинг - react-router-dom. Тосты - react-hot-toast. Тесты - Jest и React Testing Library.

## Как запустить

```bash
npm install
npm run dev
```

В браузере открыть http://localhost:5173

## Сборка и проверки

```bash
npm run build
npm run lint
npm test
```

В .env можно задать `VITE_API_BASE_URL` если бэк на другом адресе. По умолчанию используется хост из задания.
