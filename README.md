# SkyFitnessPro

Диплом по вебу. Сайт с тренировками на React и TypeScript.

Есть курсы, вход по логину, профиль с моими курсами. Можно проходить уроки и сохранять прогресс (сколько сделал повторений).

## Что есть

- Главная - курсы, кнопка "добавить в профиль"
- Страница курса - про него и список уроков
- Вход и регистрация - окошко по кнопке "Войти"
- Профиль - мои курсы, прогресс в процентах, удалить курс
- Урок - видео и упражнения, можно записать свой прогресс
- Работает на телефоне

## Чем делал

React, TypeScript, Vite, Tailwind. Тесты - Jest.

## Запуск

```bash
npm install
npm run dev
```

Потом открыть: http://localhost:5173
