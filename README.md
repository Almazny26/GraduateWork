# SkyFitnessPro

Это дипломный проект для курса «Веб-разработка».
Проект сделан на React + TypeScript и включает страницы курсов, авторизацию, профиль и тренировки.

## Что тут есть

- главная страница с курсами
- страница курса
- авторизация и регистрация
- профиль пользователя
- страница тренировки с сохранением прогресса
- адаптивная верстка под мобильные экраны

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS
- Jest + React Testing Library

## Как запустить

1. Установить зависимости:

```bash
npm install
```

2. Запустить проект:

```bash
npm run dev
```

3. Открыть в браузере:

```text
http://localhost:5173
```

## Переменные окружения

Нужен файл `.env` в корне проекта.
Пример:

```env
VITE_API_BASE_URL=/api/fitness
```

Если есть внешний сервер API, можно указать его адрес вместо `/api/fitness`.
